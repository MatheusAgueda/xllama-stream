# apply_shader_dir): compile-gpugemv-shader.sh variants writes each line to
# <out>/<tag>/<slot>.dxil, a raw DXIL container the backend loads in place of
# the built-in blob of that pipeline slot. A variant keeps the slot's root
# signature, constants and grid, and the device selftest checks it against the
# CPU before a model runs on it.
# <tag> <slot> <source> [dxc args...]
